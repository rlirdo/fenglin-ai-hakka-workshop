## 學生實際操作版（`index.html`）分頁

0. 研習前準備：只要一個 Google 帳號，不必付費（Chrome、Gemini、Gemini Notebook、手機掃 QR）
1. 今天流程（調查後新配置，每節分鐘數與產出）
2. 第 1 節：情境圖、對話修改、客語情境卡；影片為講師示範，有額度的老師跟做
3. 第 2 節：四旋鈕前後對照、影片旋鈕、幼兒教具步驟圖（四格、只有數字）
4. 第 3 節：需求對照表 → 整理教案（客語教案小幫手 Gem＋整理教案提示詞＋Gemini Notebook）→ 通知變語音 → 親師通知單（長版＋LINE 短版）→ 園務待辦表（含示範假資料）→ 繪本 → Canvas 互動小遊戲＋示範遊戲連結
5. 第 4 節：四條軌道（A 情境卡、B 分鏡、C 主題包、D 遊戲軌）與發表規則
6. 檢核：給幼兒用的六個設計原則＋回教室五項檢核、客語詞表草案、回家練習三題

可用錨點直接開到某一頁，例如 `#s3`（第 3 節）、`#check`（檢核）。

## 示範遊戲（`game/index.html`）

無計時、無分數、無聲音、無客語字、無外部資源；六題隨機，答對放大＋星星＋「好棒！」，答錯只輕輕搖動；完成後「再玩一次」。上方灰色小字提示列給老師看（華語意思），客語由老師唸。支援 `prefers-reduced-motion`。

## 注意

- 不要上傳幼兒照片與姓名。畫面交給 AI，客語交給老師。網頁不放任何學員姓名與信箱。
