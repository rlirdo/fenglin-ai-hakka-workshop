# 提示詞複製頁｜鳳林國小附設幼兒園客語社群 AI 研習

研習：AI 幫客語教學做教材：從一張情境圖到一支小影片（2026/11/14，鳳林國小附設幼兒園 客語社群教師增能研習）

網址：https://rlirdo.github.io/fenglin-ai-hakka-workshop/

## 用途

研習當天，老師用手機或筆電打開這一頁，按「複製」就能把提示詞貼到 Gemini 或 NotebookLM，不必看投影抄字。

分頁：

1. 今天流程（四節時間表、三段式學法、安全守則）
2. 第 1 節：情境圖、客語情境卡、圖變影片提示詞
3. 第 2 節：四旋鈕（風格、動作、光影、鏡頭）改之前／改之後，以及影片旋鈕
4. 第 3 節：NotebookLM 建筆記本、家長語音總覽、Gems 設定、Gemini 繪本；工具連結
5. 第 4 節：三條軌道任務與發表規則（每人兩分鐘）
6. 回教室檢核清單與客語詞表（四縣腔草案，請社群老師審核）

可用網址加錨點直接開到某一頁，例如 `#s2`（第 2 節）、`#check`（檢核與詞表）。

## 注意

- 不要上傳幼兒照片與姓名。畫面交給 AI，客語交給老師。
- 工具介面、功能與額度以研習當天畫面為準。
- 單一 `index.html`，內嵌 CSS／JS，不依賴外部資源。內容來源為研習課程藍圖與簡報。
