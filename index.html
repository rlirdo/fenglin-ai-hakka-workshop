三段式學法

  1. 跟著做：大家同一題，提示詞直接複製。
  2. 改一個字：每次只轉一個旋鈕，看前後差異。
  3. 自己玩：選一條軌道，做自己班上的教材。

四條安全守則

  • 幼兒照片不上傳：孩子的照片、影片都不丟進 AI 工具；範例用虛構角色。
  • 個資不給 AI：姓名、生日、家長電話、地址都不輸入；需要時用「幼兒甲」。
  • 內容要審適齡：看畫面有沒有可怕、暴力或刻板印象；文字與客語，老師再看一次。
  • 標示 AI 生成：教材角落註明「AI 生成，教師審核」。

01 / 統一實例引導

第 1 節：鳳林客家小鎮的早晨

大家同一題。按「複製」，貼到 Gemini 的輸入框送出。

1. 情境圖提示詞

開新對話；有工具選單時，先選「圖片」類功能（以當天畫面為準）。

一隻穿黃色雨衣的小兔子，騎著紅色腳踏車，經過鳳林的客家菸樓、禾埕和綠色稻田，要去幼兒園上學。兒童繪本插畫風格，色彩柔和明亮，早晨的陽光，橫式 16:9，畫面裡不要有文字。

✓ 小兔子、黃雨衣、紅腳踏車　✓ 看得到菸樓、禾埕或稻田　✓ 橫式畫面，圖上沒有文字

圖不滿意？在同一個對話接著說（一次只改一件事）

把腳踏車改成藍色，其他都不要變。
換顏色
在禾埕旁邊加一隻小黃狗。
加東西
背景保留，只把小兔子的表情改成開心大笑。
重畫一部分

2. 客語情境卡提示詞

在同一個對話接著說。標籤留白，客語由老師自己填。

把這張圖做成教學情境卡：在菸樓、稻田、腳踏車、小兔子旁邊各留一個白色圓形標籤，標籤裡先不要放字，我會自己填客語。

✓ 四個白色圓形標籤　✓ 標籤裡沒有任何字　✓ 印出後老師填客語

3. 圖變影片提示詞

選影片功能 → 附上剛剛的圖 → 貼上提示詞送出。只描述「動」的部分。

小兔子慢慢向前騎，風吹動稻田，鏡頭緩緩跟著小兔子移動，背景只有鳥叫聲和輕快的音樂，沒有人聲，8 秒。

✓ 小兔子有往前騎　✓ 稻田有被風吹動　✓ 沒有人聲，約八秒

影片免費額度有限。額度不足：先看講師投影示範，先完成情境圖與詞卡。

影片旋鈕也是一次只改一個；聲音一律不要人聲，客語由老師配。長度依工具可選。

初學任務（15 分鐘）

  1. 回到第一節的對話，複製原本的提示詞
  2. 挑一個旋鈕（建議先挑「風格」）
  3. 只改一個關鍵字，其他一字不動
  4. 兩張圖下載後並排存檔

完成標準：兩張只差一處，說得出是哪個字。

進階任務

  1. 轉兩個不同的旋鈕，各做一組前後對照
  2. 挑一張最喜歡的圖
  3. 做成情境卡、詞卡、繪本頁
  4. 想好每種教材要配哪些客語詞

完成標準：兩組對照＋三張教材，客語留白。
